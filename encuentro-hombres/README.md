# Encuentro de hombres · RÍO

Sitio informativo independiente en HTML, CSS y JavaScript, con recursos locales.

## Uso

Servir esta carpeta como directorio raíz con cualquier alojamiento estático. No requiere compilación, claves ni dependencias. Para probar localmente: `python3 -m http.server 8080`.

## Inscripción

El botón Inscríbete lleva al formulario. Valida nombre, teléfono y correo opcional y permite revisar los datos; aún no almacena ni envía inscripciones. La fecha, sede, costo y destino del envío están pendientes de confirmar.
